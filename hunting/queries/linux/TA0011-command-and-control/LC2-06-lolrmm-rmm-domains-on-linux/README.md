# LC2-06 LOLRMM: RMM vendor and relay domains on Linux

| | |
|---|---|
| Tactic | TA0011 Command and Control |
| ATT&CK | T1219 Remote Access Tools, T1105 Ingress Tool Transfer, T1071.001 Web Protocols |
| Indexes | `logstash-*`, `auditd-*`, `linuxconfig-*`, `browsinghistory-*` |
| Needs | any of them |
| Roles | every Linux host (baseline) |
| Source | [LOLRMM](https://lolrmm.io) catalog, generated by [`tools/lolrmm.py`](../../../../tools/lolrmm.py): do not edit `query.esql` by hand |

**What it finds.** URLs on an LOLRMM domain (or a subdomain of one) in command lines (sudo, cron, audited executions, journal `_CMDLINE`), in configuration lines (cron entries, startup files, systemd `ExecStart`) and in browser history. Linux evidence has no DNS log, so URLs are what is left; the domain filter is the same as [C2-13](../../../windows/TA0011-command-and-control/C2-13-lolrmm-rmm-domains-and-addresses/).

**Reading the output.** Sorted by score: 2, +2 for a command line or configuration line, +2 when the URL was piped into a shell or Python (`curl ... | sudo bash`, the usual agent install one-liner, for example Dataplicity's), +1 when only one host has it. Match the time against [LC2-05](../LC2-05-lolrmm-rmm-tools-on-linux/) for the agent it installed.

**If it errors.** `Unknown column [url.domain]` (or `url.original`): no browser history was loaded for any host in `FROM`. Remove `browsinghistory-*` from `FROM` and the two `url.*` fields, or let `SOF-ELK_RunChecklists.py` stub them. Otherwise remove the family that is not loaded.
