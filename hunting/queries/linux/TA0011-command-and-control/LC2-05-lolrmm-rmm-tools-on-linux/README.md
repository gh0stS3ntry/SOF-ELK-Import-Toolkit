# LC2-05 LOLRMM: RMM and remote-access tools on Linux

| | |
|---|---|
| Tactic | TA0011 Command and Control |
| ATT&CK | T1219 Remote Access Tools, T1543.002 Systemd Service |
| Indexes | `logstash-*`, `auditd-*`, `bodyfile-*`, `linuxconfig-*` |
| Needs | any of them (they come with every UAC collection; `auditd-*` only where auditd runs) |
| Roles | every Linux host (baseline) |
| Source | [LOLRMM](https://lolrmm.io) catalog, generated by [`tools/lolrmm.py`](../../../../tools/lolrmm.py): do not edit `query.esql` by hand |

**What it finds.** Linux RMM agents from the LOLRMM catalog (MeshCentral, Dataplicity, NetBird, Nezha, tmate, Teleport Connect, GLPI Agent, Chrome Remote Desktop and about 25 others): programs that ran (audited executions, and every process that wrote to the journal, with its `_EXE` and command line), files on disk (bodyfile) under their install paths (`/opt/dataplicity/...`, `/etc/netbird/...`), and systemd units by name (`nezha-agent.service`) or by the program in `ExecStart`. Bare program names are used only when they come from a documented install path and are distinctive. One row per host, tool, source, program and unit.

**Reading the output.** Sorted by score: 2, +2 when the program ran, +1 for a systemd unit, +2 for a program in a home or temporary folder, +1 when only one host has it. Any agent the client does not use is a lead; the unit file time (in `linuxconfig-*`, when the unit was written) and the first run give the install time. URLs used to fetch agents are in [LC2-06](../LC2-06-lolrmm-rmm-domains-on-linux/); the general tunnel and reverse-shell hunt is [LC2-01](../LC2-01-reverse-shells-tunnels-and-proxies/).

**If it errors.** Remove the family that is not loaded from `FROM`.
