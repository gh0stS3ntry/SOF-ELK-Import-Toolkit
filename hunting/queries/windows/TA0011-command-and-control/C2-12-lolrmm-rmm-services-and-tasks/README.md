# C2-12 LOLRMM: RMM services and scheduled tasks

| | |
|---|---|
| Tactic | TA0011 Command and Control |
| ATT&CK | T1219 Remote Access Tools, T1543.003 Windows Service, T1053.005 Scheduled Task |
| Indexes | `evtxlogs-*`, `registry-*` |
| Needs | any of System 7045, Security 4697 ("Audit Security System Extension") and 4698, Task Scheduler Operational (106, 140, 200, 201), RECmd `Services` plugin output |
| Roles | all (baseline) |
| Source | [LOLRMM](https://lolrmm.io) catalog, generated by [`tools/lolrmm.py`](../../../../tools/lolrmm.py): do not edit `query.esql` by hand |

**What it finds.** Services and scheduled tasks of LOLRMM tools: service installs (7045, 4697), task registrations and runs (4698, Task Scheduler 106/140/200/201) and the services in the SYSTEM hive (RECmd Services plugin). Each is matched on the service name or display name (`AteraAgent`, `ScreenConnect Client (*)`, `Splashtop® Remote Service` ...), the task name, and the program in its command (name and install folder). One row per host, source, service or task and program.

**Reading the output.** Sorted by score: 2 for a match, +1 for an install or registration event (it carries the time and, for 4697/4698, the account), +2 for a program in a user-writable folder, +1 for a scheduled task (some RMM agents keep themselves alive with one), +1 when the service name is an RMM's but its program is outside `Program Files` (a renamed or hand-made service), +1 when only one host has it. The service install time is usually the RMM install time; check who was logged on then ([LM-03](../../TA0008-lateral-movement/LM-03-logon-sessions-with-duration/)) and what ran right before ([C2-10](../C2-10-lolrmm-rmm-process-execution/)). The general service and task hunts are [PE-05](../../TA0003-persistence/PE-05-service-install-events/), [PE-03](../../TA0003-persistence/PE-03-services-registry-scoring/) and [PE-07](../../TA0003-persistence/PE-07-task-scheduler-per-task/).

**If it errors.** `Unknown column`: let `SOF-ELK_RunChecklists.py` add the missing fields, or add `| EVAL <field> = TO_STRING(NULL)` after `FROM` for each one named (for example `registry.plugin.display_name` when no registry was loaded, or `winlog.payload.event_data.TaskContent` without 4698 events).
