# C2-11 LOLRMM: RMM and remote-access tools in execution and install artifacts

| | |
|---|---|
| Tactic | TA0011 Command and Control |
| ATT&CK | T1219 Remote Access Tools, T1219.002 Remote Desktop Software |
| Indexes | `prefetch-*`, `amcache-*`, `shimcache-*`, `srum-*`, `registry-*` |
| Needs | any of them; `registry-*` needs RECmd `UserAssist` and/or `BamDam` plugin output. Remove the families you did not load from `FROM` |
| Roles | all (baseline) |
| Source | [LOLRMM](https://lolrmm.io) catalog, generated by [`tools/lolrmm.py`](../../../../tools/lolrmm.py): do not edit `query.esql` by hand |

**What it finds.** One row per host and LOLRMM tool, from every execution and install artifact the toolkit loads: Prefetch (program name, first 29 characters), Amcache file entries (path and SHA-1) and ProgramEntries (install folder), ShimCache, SRUM, BAM and UserAssist (path, with UserAssist's known-folder GUIDs turned back into paths). Programs are matched by name, by install folder pattern and, for Amcache, by the SHA-1 values LOLRMM lists. `artifacts` says which artifacts saw the tool, `matched_on` what matched (`name`, `path`, `sha1`), `exe_dirs` where it was.

**Reading the output.** Sorted by host, then score: 2 for any LOLRMM tool (0 for Windows' own `mstsc.exe`, `msra.exe`, `quickassist.exe`), +1 when an artifact that records a run (Prefetch, BAM, UserAssist, SRUM) saw it, +2 for a copy in a user-writable folder, +2 for a SHA-1 listed by LOLRMM, +1 when only one host has the tool. `first_seen` and `last_seen` mix artifact times; their meaning per artifact is in [EX-15](../../TA0002-execution/EX-15-execution-evidence-pivot/) (ShimCache time is the file's modification time, Amcache the key write time, Prefetch the last run, ProgramEntries the install time). Pivot on the exe name with EX-15 for the full execution story, and on the install folder with [C2-14](../C2-14-lolrmm-rmm-files-on-disk/).

**False positives.** As for [C2-10](../C2-10-lolrmm-rmm-process-execution/): ask the client which RMM products they use; LOLRMM also lists general tools that can be used for remote access.

**If it errors.** Remove the family that is not loaded from `FROM` and the fields only it has (`kape.prefetch.*` for Prefetch, `amcache.*` and `package.*` for Amcache, `srum.*` for SRUM, `registry.*` for the registry).
