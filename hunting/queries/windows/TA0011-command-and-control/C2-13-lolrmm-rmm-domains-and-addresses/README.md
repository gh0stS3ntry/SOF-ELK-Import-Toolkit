# C2-13 LOLRMM: RMM vendor and relay domains and addresses contacted

| | |
|---|---|
| Tactic | TA0011 Command and Control |
| ATT&CK | T1219 Remote Access Tools, T1071.001 Web Protocols, T1105 Ingress Tool Transfer |
| Indexes | `evtxlogs-*`, `browsinghistory-*` |
| Needs | any of Sysmon 22 and 3, DNS-Client Operational (3006, 3008, 3020), BITS-Client Operational, Security 4688 or Sysmon 1 with command lines, BrowsingHistoryView output |
| Roles | all (baseline); end-user workstations for browser downloads |
| Source | [LOLRMM](https://lolrmm.io) catalog, generated by [`tools/lolrmm.py`](../../../../tools/lolrmm.py): do not edit `query.esql` by hand |

**What it finds.** Host names that are, or are under, a domain LOLRMM lists for an RMM tool (vendor sites, relays, download servers, about 580 domains and a few wildcard names such as `relay-*.net.anydesk.com`), and the few IP addresses it lists, seen in DNS queries (Sysmon 22, DNS Client), connections (Sysmon 3 host name or address), BITS jobs, URLs in process command lines (4688, Sysmon 1) and browser history. A domain matches itself and its subdomains on label boundaries (`net.anydesk.com` matches `relay-1.net.anydesk.com`, not `xnet.anydesk.com`). LOLRMM entries marked as shared infrastructure, placeholders, public suffixes and hosting platforms (`github.com`, `amazonaws.com` roots, `blob.core.windows.net` roots ...) are left out by the generator; tenant names under them (a specific S3 bucket or Azure blob account) are kept.

**Reading the output.** One row per host, tool, source, program and matched name or address, sorted by score: 2, +1 when the evidence is not browser history, +2 for a URL in a command line or a BITS job (an installer fetched by script), +1 when only one host contacted it. `program` is the process (Sysmon) or the browser. A browser visit to a vendor's download page followed by a first run in [C2-10](../C2-10-lolrmm-rmm-process-execution/) or [C2-11](../C2-11-lolrmm-rmm-execution-artifacts/) is the usual "support call" pattern.

**Limits.** Only the first URL of a command line is read. Hosts without Sysmon and without the DNS Client log record no DNS queries; WFP events (C2-06) have addresses only, and LOLRMM lists few addresses.

**If it errors.** Remove `browsinghistory-*` from `FROM` (and `url.*`, `browsinghistory.*`, `user.name`) if no browser history was loaded, or let `SOF-ELK_RunChecklists.py` stub the missing fields.
