# C2-10 LOLRMM: RMM and remote-access tools in process creation events

| | |
|---|---|
| Tactic | TA0011 Command and Control |
| ATT&CK | T1219 Remote Access Tools, T1219.002 Remote Desktop Software, T1036.005 Match Legitimate Name or Location |
| Indexes | `evtxlogs-*` |
| Needs | Security 4688 and/or Sysmon 1. The PE original name and SHA-256 tests need Sysmon 1 (`OriginalFileName`, `Hashes` with SHA256) |
| Roles | all (baseline) |
| Source | [LOLRMM](https://lolrmm.io) catalog, generated by [`tools/lolrmm.py`](../../../../tools/lolrmm.py): do not edit `query.esql` by hand |

**What it finds.** Every process start where the program, its parent, its PE original name or its SHA-256 belongs to an RMM or remote-access tool in the LOLRMM catalog: the program name (`anydesk.exe`, `ScreenConnect.ClientService.exe`, about 800 names), its install folder (`\Program Files (x86)\ATERA Networks\AteraAgent\...`, about 500 folder patterns), and the file hashes LOLRMM lists. One row per host, program, parent, original name and hash, with the number of starts, first and last start, accounts and up to ten command lines; `tools` names the LOLRMM entries and `matched_on` says what matched (`image`, `image_path`, `parent`, `parent_path`, `original_name`, `sha256`).

**Reading the output.** Sorted by score:

| Signal | Score |
|---|---|
| the RMM program itself ran (2), or only its parent is an RMM program (1) | 1 to 2 |
| renamed: Sysmon's PE original name is an RMM program, the file name on disk is not | +3 |
| a shell, LOLBin or admin command (`cmd`, PowerShell, `net`, `reg`, `sc`, `schtasks`, `vssadmin` ...) started by the RMM program, i.e. someone working through it | +3 |
| SHA-256 listed by LOLRMM | +2 |
| RMM program in a user-writable folder (`Users\Public`, `ProgramData`, `AppData`, `Downloads`, `Temp` ...) | +2 |
| program seen on one host only | +1 |
| Windows' own remote-access programs (`mstsc.exe`, `msra.exe`, `quickassist.exe` ...) | base 0 |

Ask the client which RMM products they use, and set those aside. The first start of any other one is often the moment of hands-on access; line it up with the logons in [LM-03](../../TA0008-lateral-movement/LM-03-logon-sessions-with-duration/) and the install in [C2-12](../C2-12-lolrmm-rmm-services-and-tasks/). Rows with only a parent match show what the remote operator ran. Process starts that were not logged still leave traces in [C2-11](../C2-11-lolrmm-rmm-execution-artifacts/).

**False positives.** Generic names (`agent.exe`, `svchost.exe`, `setup.exe`, names of three letters or fewer) only match in their documented folder, but some product names are common words (`level.exe`, `teams.exe`) or legitimate software that LOLRMM lists because it can be abused (VNC viewers, PuTTY, WinSCP). The tool name in `tools` tells you which.

**If it errors.** `Unknown column`: add `| EVAL winlog.payload.event_data.<Field> = TO_STRING(NULL)` after `FROM` for the field named (4688-only collections have no `Image`, `ParentImage`, `OriginalFileName`, `Hashes`, `User`), or let `SOF-ELK_RunChecklists.py` do it.
